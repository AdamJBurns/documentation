## What is where

| Path | What |
|------|------|
| `deploy/helm/atoll` | Helm chart for the platform itself: namespaces, RBAC, config, server, ingress, network policies, optional bundled Postgres/SeaweedFS/zot for evaluation |
| `deploy/selfhost/helmfile.yaml.gotmpl` | Every release in install order, the platform included |
| `deploy/selfhost/environments/` | `default.yaml` (production template) and `local.yaml` (k3d rehearsal) |
| `deploy/selfhost/values/` | Values of each dependency |
| `deploy/selfhost/charts/` | Small local charts: MetalLB pool, ClusterIssuers, the CloudNativePG cluster, network policies of the registry and monitoring namespaces |
| `deploy/selfhost/k3s/` | k3s install script and config |
| `deploy/selfhost/scripts/create-secrets.sh` | Creates namespaces and all Secrets (storage ones through `create-storage-secrets.sh`) |
| `deploy/selfhost/local/k3d.sh` | Rehearse the whole install on a local k3d cluster |

## Component choices

| Need | Choice | Why |
|------|--------|-----|
| Kubernetes | k3s | Single binary, embedded etcd for HA, easy on bare metal and small VMs |
| Load balancer | MetalLB (L2) | Gives the ingress a stable IP on bare metal without a cloud |
| Ingress | Traefik | ingress-nginx was retired in March 2026 (no more fixes). Traefik is maintained, handles Ingress and Gateway API, and is k3s' default |
| Certificates | cert-manager | HTTP-01 for single hosts and users' custom domains, DNS-01 (Cloudflare or RFC2136) for `*.apps` |
| Postgres | CloudNativePG + Barman Cloud plugin | Streaming replicas, automatic failover, continuous WAL archiving and point-in-time restore |
| Object storage | SeaweedFS | Apache-2.0, S3 API, replication across volume servers. MinIO's community edition no longer ships images |
| Registry | zot, blobs in SeaweedFS | See [registry.md](/self-hosting/registry) |
| Metrics | metrics-server, kube-prometheus-stack | HPAs, billing (CPU/memory and Traefik bandwidth), dashboards, alerts |
| Logs | Loki + Alloy | One Loki process, Alloy tails every pod through the API |
